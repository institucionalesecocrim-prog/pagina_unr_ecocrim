# EcoCrim — Novedades

Componente de novedades para insertar en la página institucional de EcoCrim mediante GitHub Pages.

## Archivo que se edita habitualmente

`novedades.json`

Ahí se modifican título, fecha, descripción, imagen, texto del botón y URL.

## Publicación

El sitio puede publicarse con GitHub Pages desde Settings → Pages → Deploy from a branch → main → / (root).
